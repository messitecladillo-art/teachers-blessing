# 循证一课 · 教材与教学

当前主线是：**上传教材 → 自动文字提取与OCR → 识别真实目录 → 按章萃取知识点 → 按章准备讲义 → 追问、练习、笔记与备课。** 这是独立实现，教材与账号不连接Mentrix；原EVI-X工程保持不变。竞赛包装暂缓。

产品差异化围绕师范生的“学懂—设计—试讲—评价—改进”。已重新核读用户提供的GitHub项目，并记录[方法吸收与教学产品路线](docs/skills-to-product.md)；其中已实现的一课时教学任务包与后续互动导师、学生图练习等提案明确分开。

书架保留用户选定的竖版封面。20页界面使用原生控件、真实教材与账户记录重建，并逐场景核验；视觉稿批准不等于全部交互1:1验收。查看[20页功能与路由](docs/ui20-pages.md)、[界面说明](docs/interface-v0.7.md)和[后续产品方向](docs/product-roadmap.md)。运行后可打开`/ui-gallery.html`对照成套设计。

当前集成回归425项通过；本轮真实与合成验证的边界见[v0.7验证记录](docs/validation-v0.7.md)。

登录前展示页位于 `/welcome`，以奶油纸色、鼠尾草绿和书籍植物版画构成“书庭学苑”。首屏、直接学习入口和静态替代不依赖三维；三维只有在本站真实SPZ载入成功后启用，详见[欢迎页运行边界](docs/world-welcome.md)。

Mentrix的章节准备、先修/难度结构、章节学习素材与产物历史、研究工具证据链已补深复核，见[功能复核v0.3](docs/reverse/Mentrix-功能复核-v0.3.md)。该报告明确区分目标静态机制、实际只读见证、本地缩减适配与未实现部分；当前没有达到全部功能等价。后续公网试点见[上线方案与验收门](docs/deployment-pilot.md)，尚未部署。

## 一课时教学任务包

在教材左下角点击“备好一堂课”，打开“一课时教学任务包”，创建目标与教材范围，生成或手工填写教案、教学图示、学生任务单、评价题和教师参考，逐块修订并保存版本。核对教师参考后确认本人审阅，再导出学生版；理解证据与试讲复盘单独归因保存。见[使用与方法落点](docs/teaching-pack.md)。

教学包已有可编辑节点、连线和安全SVG输出的流程/关系图，正文支持公式。知识点概率树、函数图及AI插图尚无自动运行链路；本轮imagegen仅用于开发素材，不代表用户在应用内已经可以生图。

试讲页已接真实模型的AI学生对话，可选择好奇、易混淆或谨慎回应，按当前教学版本保存最多12轮本人讲解。任务、教材版本变更会阻止旧会话继续；取消和恢复沿用后台任务。已用自编公开数学材料完成3次真实供应商回应验证，另以合成QA验证两轮保存及刷新回看；这些模拟不代表真实班级反馈或教学能力认证。见[AI学生服务](docs/mentrix-student-simulation.md)。

学习工具中提供手选的贝叶斯概念实验、自报信心与实际作答诊断、持久复习计划。实验参数为教学设定，诊断基于实际选择题参考；两者不作为真实学习效果或能力认证。

## 一键导入教材

上传后启动全书解析，默认全书、全部知识点讲义，也可选择真实章节范围或调整备课方式。系统自动连续处理，不要求用户反复手选下一批页码；已完成章节可先学，其余继续。

- OCR每批最多5页、结构整理每片最多20页是内部安全预算。长章分片后合回原章，页块不是章节。
- 优先采用书签、可靠目录与物理正文章标题，校准印刷页和PDF物理页。无法可靠识别时进入“目录待核对”，不以“第1–20页”伪造课程章。
- 可取消并显式继续；重启、缺语言包、预算不足或待核对均保留已完成内容。已完成分片复用，来源/人工目录变化阻止迟到覆盖。
- 默认累计100次模型请求，可显式提高至200，仍受每日预算约束；逐知识点研究也进入该上限。达到上限会停下等待继续，不假装整书就绪。

高级范围OCR保留作定点修复。见[一键导入](docs/book-import.md)和[扫描恢复说明](docs/mentrix-scan-recovery.md)。

## 开始使用

安装 Node.js 22.16+：

```powershell
npm ci --ignore-scripts
if (!(Test-Path .env)) { Copy-Item .env.example .env }
# 在 .env 配置新的模型 Key、API URL 和模型 ID；不用填写旧公开 Key
npm run setup:ocr
npm start
```

打开 **<http://127.0.0.1:3285/study>**，注册本机账号。推荐路线：**上传 → 一键全书解析 → 核对真实目录与来源 → 进入已就绪章节 → 讲解/追问/练习 → 笔记与教学包**。

`setup:ocr`从固定官方来源下载中/英文语言包并校验SHA-256，扫描识别需要它。纯文字PDF/Markdown的基础文字提取无需模型或OCR包；全书AI结构整理、讲义、出题和追问需要模型。未配置明确提示，不返回假生成内容。联网研究使用独立模型配置，可关闭。

## 真实运行边界

课题问答采用轻量RAG：按实际问题检索本人课题材料与关联教材，取带出处的片段交给模型，并校验返回的来源ID。目前使用中英文关键词检索；Embedding、向量数据库与重排序尚未接入。知识图鉴展示目录隶属关系。细节见[检索说明](docs/mentrix-retrieval.md)和[教材联动](docs/mentrix-linked.md)。

教材PDF≤300MiB/3000页、Markdown≤5MiB；课题普通文件≤30MiB、Markdown≤5MiB，最多10份。5页OCR/20页结构片段为内部安全批量，不是主流程需要反复手选的限制。已用自编3000页PDF与超过31MiB有效PDF验证提取；未测试完整300MiB实体或所有稠密3000页输入，文字量、输出、时间与内存预算保留，见[容量说明](docs/mentrix-pdf-capacity.md)。

本轮隔离处理一份416页扫描输入：414页取得文字、5个正文真章；全书文字/OCR核算包含前置页和章后材料，其余2页仍无文字并保留partial。外部provider调用为0，知识点与讲义用Mock验证课程调度链，**不是整本真实学科内容质量验收**。可读章节不等于416页文字全覆盖。

联网研究另行验证：原`gpt-4.1-mini`实测检索或引用不足，未作为成功放行。经用户同意，研究采用独立`gpt-5-mini`；一份真实completed回执有Bilibili/中文维基来源与引用链，规范化去重后保留10个已引用来源及2个检索来源。校验复用已录响应，不新增调用。单次成功不保证每点搜到知乎，也不等于读完网页/看过完整视频。研究仅发送公共书名、章名与知识点标题，不发教材原文、笔记或私有会话；一次研究计一次本机模型请求，托管搜索工具另收费，任务单位不是账单。见[研究说明](docs/knowledge-research.md)。

资料在本机私有数据目录持久化，原件不进入静态公开目录。当前为单进程本机运行；GitHub Pages只展示静态文件，不能运行私有账号、模型代理和学习服务。短信、支付按用户决定暂不启用；公网多实例部署尚未验收；设备朗读使用浏览器语音，实际设备表现需核验。

详细接口与边界：[账号/基础对象](docs/mentrix-api.md)、[教材学习服务](docs/mentrix-learning.md)、[模型代理](docs/model-proxy.md)。
