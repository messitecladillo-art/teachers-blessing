# 教材学习 · 私人 AI 课程

当前先落实 Mentrix 的核心能力：**把一本教材变成可以逐个知识点讲解、追问、练习和记录的私人课程。** 这是独立实现，教材与账号不连接 Mentrix；原 EVI-X 工程保持不变。竞赛包装暂缓。

产品差异化围绕师范生的“学懂—设计—试讲—评价—改进”。已重新核读用户提供的GitHub项目，并记录[方法吸收与教学产品路线](docs/skills-to-product.md)；其中已实现的一课时教学任务包与后续互动导师、学生图练习等提案明确分开。

## 一课时教学任务包

在教材页面打开“一课时教学任务包”，创建目标与教材范围，生成或手工填写教案、教学图示、学生任务单、评价题和教师参考，逐块修订并保存版本。核对教师参考后确认本人审阅，再导出学生版；理解证据与试讲复盘单独归因保存。见[使用与方法落点](docs/teaching-pack.md)。

扫描教材出现“没有可提取文字”时，可选择本课需要的页码进行本机OCR；系统保留实际页数、待处理页与分批结果。当前PDF内嵌图预算16M像素，直接图片上传仍12M像素；过大页面明确提示。见[扫描恢复说明](docs/mentrix-scan-recovery.md)。

## 开始使用

安装 Node.js 22.16+：

```powershell
npm ci --ignore-scripts
if (!(Test-Path .env)) { Copy-Item .env.example .env }
# 在 .env 配置新的模型 Key、API URL 和模型 ID；不用填写旧公开 Key
npm run setup:ocr
npm start
```

打开 **<http://127.0.0.1:3285/study>**，注册本机账号。推荐路线：**上传教材 → 核对目录和页码 → 选择知识点 → 生成讲解 → 追问 → 作答与反馈 → 笔记/导出**。

`setup:ocr` 是可选步骤，从固定官方提交下载中/英文语言包并校验SHA-256；扫描件识别需要它。纯文字PDF/Markdown解析无需模型Key，也不需要OCR语言包。AI讲解、出题、反馈和追问需要已配置模型；未配置会明确失败，不返回伪造的生成内容。

## 真实运行边界

课题问答采用轻量RAG：按实际问题检索本人课题材料与关联教材，取带出处的片段交给模型，并校验返回的来源ID。目前使用中英文关键词检索；Embedding、向量数据库与重排序尚未接入。知识图鉴展示目录隶属关系。细节见[检索说明](docs/mentrix-retrieval.md)和[教材联动](docs/mentrix-linked.md)。

教材PDF目前≤300 MiB/3000页，Markdown≤5 MiB；课题普通文件≤30 MiB、Markdown≤5 MiB，最多10份。OCR每任务最多5页，未识别页保持partial，可继续指定范围；文字需人工核查。AI课程提案每次最多20页。已用真实自编3000页PDF和超过31MiB的有效PDF验证提取；未声称测试过完整300MiB实体，详见[容量说明](docs/mentrix-pdf-capacity.md)。解析仍有文字量、时间与内存预算。

资料在被忽略的 `.local/learning/` 持久化，原件不进入静态公开目录。当前为单进程本机运行；GitHub Pages只展示静态文件，不能运行私有账号、模型代理和学习服务。短信、支付按用户决定暂不启用；公网多实例部署尚未验收；设备朗读使用浏览器语音，实际设备表现需核验。

详细接口与边界：[账号/基础对象](docs/mentrix-api.md)、[教材学习服务](docs/mentrix-learning.md)、[模型代理](docs/model-proxy.md)。

## 验证

```powershell
npm run check
npm test
```

自动测试包含真实自制PDF解析、本机语言包可用时的真实扫描OCR、模拟模型合同、用户隔离、预算、取消/晚到、来源版本、作答幂等、浏览器批注和离线导出。`npm test`采用本机mock模型，不消耗模型额度；可选OCR与浏览器检查缺资源时会明确skip，Chrome可用`CHROME_PATH`指定。本轮自动检查与新增能力的独立浏览器记录见[验证说明](docs/mentrix-validation.md)；此前v0.3的110项自动测试、49项普通界面与10项数学记录作为历史快照保留。

另用自编教材完成了真实模型的带引用讲解、追问、选择/简答出题及学习反馈验证。没有使用旧密钥或真实学生数据，不将模型分数当作能力认证。私有浏览器与调用证据在被忽略的 `.collab/mentrix/evidence/`，公开记录见[验证说明](docs/mentrix-validation.md)。
