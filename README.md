# 循证一课 · 师范生成长驿站

教育 AIGC 教学应用原型，整合原有 `teachers-blessing` 门户与 EVI-X 的独立源码副本。具体场景是**初中统计调查项目学习**：先核对证据，再生成可由教师修改的教学草稿。

## 当前可以运行的功能

- 保留师范生成长门户、教学演练、自定义 Agent、Agent Studio 和 PPT 编辑器。
- 新增本地 CSV 工作台：分类频数、有效分母、缺失统计、图表、来源声明、教师核对、Markdown / PPT 证据导出。
- 一键把**汇总结果**填入教案输入框，教师主动生成时才请求模型。原始 CSV 不经工作台上传。
- 模型调用统一经过同源 Node 服务；密钥只读取服务端环境变量。未配置时明确报错，不将内置范例冒充生成结果。
- 模型 Markdown 和 PPT 文本经过安全处理。示例调查与能力雷达均标注为合成演示。

这是功能原型。EVI-X 的 Next.js / FastAPI 应用仅以源码副本形式收入，尚未与本门户共享账号、数据库或教学 API；完整教学对象、版本差异和试教评估仍是下一阶段工作。没有用本次 mock 测试证明真实模型效果或教学效果。

## 本地启动

安装 Node.js 22.16+，无需安装根项目 npm 依赖：

```powershell
Copy-Item .env.example .env
# 编辑 .env：填入新建的服务端模型 Key、模型 ID 与服务地址
npm start
```

打开 <http://127.0.0.1:3285>。不填 Key 也可体验 CSV 示例、教师核对和证据导出；AI 教案、对话、模拟反馈及 Studio 需要配置模型。设置详见 [模型代理文档](docs/model-proxy.md)。请勿把 `.env` 提交到 Git。

推荐体验：**循证一课 → 加载合成示例 → 核对总数与有效分母 → 教师确认 → 填入教案 → 主动生成草稿**。再打开 Agent Studio，用明确指令生成课件并在编辑器中修改、导出。

GitHub Pages 只提供静态预览，不运行 Node 模型代理。公网运行前需配置 HTTPS、访问控制和调用预算；当前代理默认仅监听本机。可选 Supabase 登录/私有 Agent 继承自原门户，需要其独立服务与权限配置。
