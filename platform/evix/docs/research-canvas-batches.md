## 首版收敛

首版用 PostgreSQL 领取任务，`FOR UPDATE SKIP LOCKED` 避免同时领取；租约支持中断恢复；业务变更、任务与 outbox 在同一事务内保存。外部调用另行预留回执，发送后缺少结果时保持待对账。任务领取机制本身不保证外部供应商只计费一次。

独立 Python worker 从数据库取任务、校验权限和版本，启动有界 Node 子进程计算。Node 使用现有 TypeScript 核心并通过标准输入输出交换结构化数据，不承担独立网络服务或数据库写入。Python 校验计算回执后写入权威数据库。后续吞吐量需要消息传输层时再启用 Celery/RabbitMQ 适配；不作为首版部署前提。

调查回收在调查状态中进行；锁定答卷创建不可变数据版本，运行只消费已锁定快照。长期回收不会占用计算任务。条件节点、表达式分支与虚线先后关系暂缓开放；首版保留数据实线和研究关联点线，并用人工确认表达必要决定。

模型材料沿用研究证据契约，跨语言共享白名单与参考样例。任何新增字段均需通过服务端校验和回归，而非默认外发。

画布运行不推进赛事阶段、不写 `.agent/state.json`、不标记 Gate 通过。赛事控制面仍由 CLI、真实证据和当前 Gate 管理。
