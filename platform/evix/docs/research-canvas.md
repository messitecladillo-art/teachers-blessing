# 研究画布

同一个研究项目提供工作台和画布两种视图。工作台负责问卷、数据、图表和成果的详细编辑，画布负责组装步骤、输入引用、分支与运行。切换视图保留已挂载的编辑器；返回画布后继续使用原有草稿。

画布入口默认隐藏。试验构建时设置 `NEXT_PUBLIC_EVIX_RESEARCH_CANVAS=true`，重建前端后开放入口。原有工作台继续按原路径使用。

画布运行记录只表示计算与成果处理，不推进赛事阶段、不写 `.agent/state.json`、不标记 Gate 通过。赛事控制面继续通过既有 CLI 和当前证据推进。

## 开始

打开已登录项目，点击顶部“研究画布”。可从节点库逐项添加，插入可编辑的参考流程，或让个人模型服务提出流程方案。已有成果的节点引用需经预览确认；系统不会为已有文件推断执行关系。

点击节点打开右侧设置，双击或点击“详细编辑”进入已有编辑器。节点只显示摘要，完整图表、报告、LaTeX 与 PDF 留在编辑区。新增、复制、删除、编组、布局和连接均保留撤销记录。删除节点不删除成果文件。

实线绑定数据端口，虚线规定必要先后关系，点线记录研究关联。点线不参与运行。编组只整理空间。可以保存配置未完成的流程；运行前检查会定位缺失输入、类型冲突、循环及实际执行范围。

## 数据与运行

CSV 在分析工作台继续进行本地预览。点击“上传并用于后台运行”，确认数据类别后，服务器建立私有不可变版本。切换画布不会上传 CSV。数据节点可选择已有私有版本。

统计节点复用分析工作台的计算核心：频数、数值描述、分组描述、交叉表、Pearson、Spearman 和信度。分组描述输出描述结果。命名汇集保留各分支的样本口径，图表和条件节点用结果名称选择具体分支。

模型服务绑定属于当前用户，保存在流程运行请求中；导出的流程配置不携带 Key 或个人服务绑定。开始模型运行前确认服务、用途及允许使用的材料。模型输入支持研究材料和汇总结果；原始答卷由后台拒绝外发。

每次运行冻结流程、输入、配置、执行器和服务修订。运行期间编辑形成新的草稿。关闭浏览器后后台任务继续，再次进入项目可载入记录、从事件序号恢复进度。取消阻止未发送调用；已经发送且无回执的模型调用进入待对账，自动恢复不会重发。

人工确认绑定节点尝试和输入哈希。调查回收绑定发布版本，锁定后生成答卷快照。超过期限时可继续等待、锁定当前数据或取消。未激活的条件分支记为跳过；失败阻塞依赖节点，独立分支继续执行。

## 图表与成果

图表节点选择类型与色系，完整格式树在图表工作台打开。三线表上、中、下线分别为 1.5、0.75、1.5 磅，每列居中。各项数值显示计算终值。

结论、报告章节及答辩节点引用真实计算回执。报告进入提案，确认应用后创建原生报告版本。Word、PPT、TeX 和 PDF 保存私有文件回执，可在节点设置中下载；报告结构由用户编辑决定。实际、合成及未知来源分类随成果版本保存，重开和再次编辑继续保留。

第十七届格式沿用已有已核实配置。组别、赛区和阶段未明确的规则继续作为待确定范围，不改变用户的章节选择。

## 动效与桌面操作

节点增删、按压、选择、面板、菜单、编组、布局、真实回执脉冲及结果显现使用统一参数。React Flow 管理位置和端口坐标，节点内部壳管理缩放和显现。布局移动与连线共享坐标，开始拖动即由用户接管。

设置提供标准、减少动态和关闭动效，系统减少动态优先。隐藏视图及页面停止循环。浮动工具使用有限玻璃材质，节点采用稳定表面。

空格加拖动平移，Ctrl 加滚轮缩放；Shift 多选，Ctrl D 复制，Ctrl Z 撤销；F 定位选中项，Shift F 适应全图。运行单次最多 50 个执行节点，计算任务并行 4 个、模型调用并行 2 个。

## 开发与验收

后端启动、权限、迁移与任务恢复见 [运行说明](../deploy/workflow-running.md)。前端依赖由根目录 `package-lock.json` 锁定，Node 要求至少 22.13。

```powershell
npm run test:workflow --workspace apps/evi-x-platform
npm run test:canvas:fixture --workspace apps/evi-x-platform -- 50
npm run test:canvas:fixture --workspace apps/evi-x-platform -- 200
```

压力输入生成在被 Git 忽略的 `.collab/runs/20261011-research-canvas/` 中，分别含 50 节点 / 80 连线、200 节点 / 500 连线。通过画布更多菜单导入，先预览再确认。生成器只生成合成布局文件，不上传数据、不调用模型。实际运行验收需配置数据版本。
