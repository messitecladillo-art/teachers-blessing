# 知识图鉴的范围与呈现

本项目的图鉴来自本人教材的真实目录：教材包含章节，章节包含知识点。节点沿用持久ID；连线仅是`contains`目录关系。没有推断先修关系、因果关系或学科语义网络，也没有把浏览器报告里的按钮名称当作原站算法证据。

界面沿用`study.css`已存在的纸白、森林绿及系统中文字体。采用已引入Diagram Design截选中“概览/详情拆分、正交树形连线、限制密度、SVG可访问说明、局部横向滚动”的约定；原上游文件与来源清单保持不变。本次是嵌入现有应用的交互组件，没有安装完整图示工具链、修改全局profile或执行未导入的检查脚本。

全书概览展示教材与章节，选择章节后查看其知识点。每张图最多4个子节点加父节点；更多项目分页，完整匹配结果保留在可操作列表中。名称搜索跨章节时不额外绘制教材到孙节点的直接边。图形具备title/desc，节点支持键盘；小屏切换单列、使用左侧目录轨道连线，并在窗口尺寸变化时重新布局。列表保留同等入口。知识点可打开对应教材位置，总结来源链接会明确打开原文页。

统计中的“掌握”只称为用户自标；节点与页码来自当前可授权数据。解析或人工目录变化后重新读取图鉴，不把旧节点复制成新的固定演示数据。来源不明的节点不会补造页码。

本组件只使用现有样式、原生DOM/SVG和后端目录DTO；没有外部字体、图片或图谱服务请求。真实浏览器的节点、筛选、来源跳转及窄屏检查见本轮验证记录。
