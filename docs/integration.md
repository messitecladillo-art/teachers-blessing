# 教育 AIGC 整合说明

本仓库以原有 teachers-blessing 教师门户为入口，保留资料、活动和教学工具，新增“循证一课”课堂证据工作台；`platform/evix/` 保存独立的 EVI-X 源码副本，供后续开发复用。当前运行的是根目录原生网页与 Node 同源代理，不能据此认定 EVI-X 的 Next 平台、数据库或账号系统已经部署。原工程不作为本仓库的运行目录。

**当前可体验：**运行 `node server.mjs`，访问 `http://127.0.0.1:3285`。先载入明确标为合成的30行图书角示例，或导入本地 UTF-8 CSV；选择分类列，程序计算频数、有效 n、缺失和占比，空值不进入比例分母。导入文件默认来源待确认，教师须选择合成演示或声明真实去标识（未经核验），再核对勾选。换数据、列、来源或课例名称会使原确认失效。表格、条形图与带数据指纹的 Markdown 可用于复核，原始答卷不会自动上传。

确认后，“用于备课”只把统计汇总填入教案输入框。教师检查并主动生成，才通过服务端代理发送内容；未配置模型时保留本地功能并提示不可生成，不伪造结果。按[模型代理说明](model-proxy.md)配置新密钥后，可请求待教师复核的教案草稿。原有 Agent Studio 可继续生成结构化课件、编辑并导出 PPT；本地统计也可导出 PPT。模型连通性、教学质量和真实付费调用不在本轮自动测试的证明范围内。

**初中统计调查45分钟课例为拟议安排：**0–5分钟提出图书角选书问题；5–12分钟检查调查问题与样本；12–20分钟整理数据和缺失；20–30分钟读频数表、条形图与有效占比；30–38分钟辨析样本结论的适用范围；38–45分钟反馈和反思。合成示例不是已发生的课堂，不能证明学习效果。

**源码复用与下一阶段：**EVI-X 已用于借鉴确定性 CSV 统计和确认失效逻辑；其问卷、权限、版本、报告等源码尚未接成当前门户服务。原详细方案面向 Next 教学模块与完整后端，本次改为先贯通现有门户、课堂证据与代理，因此不能把方案全部 P0 标为完成。下一阶段须经教师核对教材、题目与量规，补齐课例保存、结构化校验、诊断计分和版本追溯；随后以新密钥验证真实调用，完成浏览器、导出与授权检查。公开评审入口还需部署鉴权、配额和演示数据隔离；真实试教与效果结论仅按实际记录陈述。
