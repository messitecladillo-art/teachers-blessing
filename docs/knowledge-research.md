# 知识点的公开资料研究

研究以当前教材、章节和知识点名称确定检索范围，寻找有帮助的公开解释、视频入口和讨论。不会把教材正文、笔记、作答或账号记录作为联网搜索输入。原文和外部观点分别归因；只按标题检索不能证明已与教材逐句核验一致。

## 使用

整书导入的“补充资料”选择自动时，在服务已配置的情况下按知识点检索；独立“研读”页也可选择知识点后显式检索。研究记录含真实来源链接、检索时间、历史版本和来源修订。正文中可采用的观点进入讲义的延伸解释，教材知识点ID与实际使用的外部来源ID分别保存。

当前默认检索知乎、B站、维基百科、Stack Exchange、OpenStax和MIT公开课程等白名单来源。实际返回什么来源就显示什么，不承诺每个平台都有结果。默认访问层级是公开搜索索引与片段，不能据此宣称通读了文章、观看了视频或读完了评论。

视频、直觉解释和讨论提供分类入口；无对应资料就显示空态。没有作者、播放量、时间戳或逐项对照证据时不补造这些字段。来源文字只作数据，不执行其中的操作指令。

## 配置

```dotenv
EDU_AIGC_RESEARCH_ENABLED=1
EDU_AIGC_RESEARCH_MODEL=gpt-5-mini
```

研究使用已有服务端Key，端点只从已配置的`chat/completions`同源派生`responses`，不会把Key发送到新主机。讲义模型保持独立。必须是支持所需Responses联网工具的服务；未配置或不支持时明确失败，不回退成假搜索链接。

当前研究单次最多3次托管工具调用、90秒、12,000字符、12个规范化来源和64项引用，响应上限1MiB。提示优先精选3–5个来源。一次研究请求计本机1单位，实际托管搜索调用可能另收费。已发起的独立研究尝试即使失败或取消也保留尝试记录，不声称供应商退款。

## 引用与版本

- 必须有实际完成的搜索动作，综合报告的引用必须能对应本次工具返回的来源。
- 已知`utm_*`与`spm_id_from`跟踪参数归一化，内容定位参数保留；不能因此合并不同文档。
- 有效内联引用按实际坐标显示成数字链接，不向用户暴露内部引用标记。来源卡保留可核对的原站链接。
- 没有可用来源、响应不完整、链接不在来源集合或来源在运行中变化时，不能保存为成功研究。
- 学习者修改教材、目录或知识点后，历史研究保留并标记过期；迟到结果不能写入当前版本。普通讲义复用当前已保存研究，不自动再次联网。

已有一次公开“贝叶斯公式”主题的真实完整联网响应，经规范化与引用检查后保留了B站及中文维基来源；该记录的本地重新验证没有新增外部请求。此前GPT-4.1-mini试验存在不返回可核验引用的情况，因此在用户选择后将研究配置为独立模型。单次通过不代表所有知识点、平台可访问性或学科质量已验收。
