# 20页原生界面：路由、数据与动作

本清单对应本轮原生接线与模块实现。20张生成设计稿是视觉目标，包含示例教材、公式、学习数值与演练结果；这些示例不是用户数据或验证结论。原生页面使用当前账户的真实记录，缺数据时显示空态，不用设计稿中的示例补齐。

设计图见`assets/ui-design/manifest.json`；设计总览不等于交互页面。下表的路由以`/study`后的hash表示，`:book`、`:chapter`、`:point`是当前账户对象的占位符，不是可直接访问的示例账号。多个设计页可共享阅读器或教学包数据和组件。

## 页面对应

| 页 | 原生入口 | 实际数据与可执行动作 | 边界 |
| --- | --- | --- | --- |
| 01 教材书架 | `#/textbooks` | 本人教材、文件夹、导入状态与已保存阅读记录；上传、进入教材、整理范围 | PDF封面为物理第一页；Markdown或预览失败保留占位，不生成假封面 |
| 02 登录与注册 | `/study`未登录状态 | 本机密码账号的注册、登录与退出；邮箱作为账号标识 | 未接邮箱验证、短信或第三方登录；设计图中的昵称不是预置账户 |
| 03 整书导入与进度 | `#/textbook/:book/import` | 实际持久父子任务、章节与覆盖计数；一键全书、取消、显式继续、预算处理 | 5页OCR与20页结构片段是内部批量，不是课程章；不可靠目录待核对 |
| 04 章节主页 | `#/textbook/:book/chapter/:chapter` | 真实章标题、知识点、来源与已完成备课状态；进入本章知识点、前后章切换 | 可学章节与全书完整覆盖分别表示，不以空白页或页块凑章节 |
| 05 知识点讲解 | `#/textbook/:book/kp/:point` | 当前知识点来源、讲义版本、自标状态与会话；生成、追问、切换版本、记笔记、导出 | AI讲义待核查；自标掌握不等于客观测评 |
| 06 原页对照学习 | `#/textbook/:book/kp/:point/compare` | 绑定原件的真实PDF物理页与讲义；翻页、缩放、分栏调整、原件下载 | 页图加载成功才显示；Markdown用提取文字。翻页不自动切知识点；尚无OCR词框与图像坐标联动 |
| 07 外部解析与讨论 | `#/research` → `#/textbook/:book/kp/:point/research` | 公共标题检索的可核验来源、引用与中文报告；查看历史、开始/取消研究、打开来源 | 需配置研究服务；不保证命中知乎，不声称读完文章或看完视频，也不凭标题断言已与教材一致 |
| 08 知识图鉴与学习路径 | `#/atlas`或`#/textbook/:book/atlas` | 真实目录图、知识清单与来源；按章/名称筛选、进入阅读；手工添加/删除/保存先修建议DAG | 目录边仅表示包含；人工先修仍待核对，服务端拒绝循环，版本冲突保留草稿；不自动推断学科先修事实 |
| 09 概念实验室 | `#/lab` | 已接手选通用贝叶斯教学模板；调整先验、灵敏度与假阳性率，查看确定性公式、概率树、先验/后验与分步说明 | 参数为本人设定的教学情境；分母为0时明确后验未定义。不是由任意知识点自动生成的实验，不代表真实检测样本 |
| 10 学习前诊断 | `#/diagnosis` | 选择本人当前知识点，生成或读取4道选择题；作答并自报信心后实际提交，持久保存本次前测与诊断历史 | 参考答案在提交前不揭示；服务端按实际参考选项核对，不接收客户端伪分数。信心为本人自评，简答在此不判分，建议不作能力认证 |
| 11 练习作答 | `#/textbook/:book/kp/:point/practice`或阅读器“练习” | 本人题集版本、选择/简答、草稿与提交历史；生成、作答、提交、显式揭晓 | 来源改变时旧题不可按当前来源继续提交；揭晓前不返回参考答案 |
| 12 作答反馈与错题 | `#/textbook/:book/kp/:point/feedback` | 真实作答、程序选择题核对与已取得的AI建议反馈；回看、显式查看解析、返回来源 | 页面名不代表已建成独立智能错题库；简答建议分和错误原因仍待核查 |
| 13 复习计划 | `#/review` | 本人持久复习项、到期日与自评历史；添加、回看来源、again/hard/good/easy、延期、取消、旧源重建 | 自评分别安排1/3/7/14天后的UTC到期时间，固定间隔不保证记忆效果；站内待办不发通知邮件或短信 |
| 14 笔记与收藏 | `#/notes`、`#/bookmarks` | 本人原文/讲义/对话/练习批注与收藏；教材/章节筛选、编辑、颜色、保存、删除、回跳 | 绑定具体来源版本；重复文本、公式或旧源可要求复核，不强行声称精确定位 |
| 15 多材料课题研究 | `#/workshops`、`#/workshops/:workshop` | 本人上传/粘贴材料、关联教材、检索来源和会话；增删资料、选择讨论、追问 | 材料检索为有界关键词检索；不代表全部材料已进入模型上下文，不是协作班级空间 |
| 16 一课时教学任务包 | `#/teaching` → `#/textbook/:book/teaching` | 实际教学目标、教材范围、内容版本；生成/手工草稿，编辑教案、图示、任务单、评价与教师参考，审阅与导出 | 来源、目标或内容变化会影响有效审阅；图示为受控结构SVG，不执行任意模型HTML/SVG |
| 17 学生版任务单预览 | `#/textbook/:book/teaching/student` | 同一教学内容版本的学生白名单预览与导出 | 不含教师参考、提示与私人复盘；这是本人预览，不等于已上线学生账号、班级发布或权限分享 |
| 18 试讲与复盘 | `#/textbook/:book/teaching/reflection` | 已有教案步骤/分钟段、理解记录、自述/手写模拟/授权去标识反馈；保存依据、反例和下次行动；真实模型驱动的AI学生对话、持久历史与取消/恢复 | AI学生每会话最多12个已发起教师轮次，明确模拟、不认证能力；手写模拟与AI对话分别保存。无自动录音或转写，模拟回复不等于真实课堂反馈 |
| 19 学习记录 | `#/statistics` | 当前账户对象计数、接口返回的近期活动、当前教材自标分布与章清单 | 近期活动有返回条数上限；不是学习时长、成绩提升或完整历史，图稿里的数值不是默认结果 |
| 20 偏好与服务设置 | `#/settings` | 持久主题、字号、新讲义风格，实际服务配置、配额与本机账本；保存偏好、跳到服务、退出 | 浏览器不存模型密钥；本机任务单位不是供应商费用或会员余额，配置可用不等于每次调用成功 |

## 验收口径

目标是按批准稿还原底色、配色、形状与布局，并保留原生交互；**当前不宣称20页已完成100%像素验收**。需要按绑定版本分别检查：1586×992实屏比较、内容长度压力、窄屏/键盘、加载/空/失败状态，以及保存、取消、冲突、跨账号和旧回包行为。单张设计稿、Node测试或生成截图不能互相代替这些验收。

当前界面使用真实页图、已有数学渲染和受控SVG；开发期图像生成是视觉素材制作，不是应用内用户生图能力。模型、OCR、浏览器和教学效果的证据层级见[功能范围](mentrix-coverage.md)。后续候选能力见[产品路线](product-roadmap.md)。

AI学生另有累计3次真实模型服务回应核验（好奇型2轮、独立易混淆型1次），仅使用公开自编数学fixture，没有实际用户或班级资料；此范围只说明受控样例调用链可运行，不推导模型教学质量、真实学生反应或课堂效果。实现、合同测试、真实调用与视觉验收仍分别判断。
