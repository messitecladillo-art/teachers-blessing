# Mentrix 功能落实清单

说明快照：2026-11-17。当前主线是 **一键导入 → 真实章节/知识点 → 来源讲义 → 追问/练习 → 本人笔记与学习成果 → 一课时教学包**。这是独立实现，不连接Mentrix账号或业务API，不把逆向报告当原服务端源码。竞赛包装暂缓。

书架、阅读与教学工作台正在按用户批准稿重建，v0.7仍迭代，视觉批准不等于全部交互1:1验收，见[界面说明](interface-v0.7.md)。目标机制与只读见证见[逆向复核v0.3](reverse/Mentrix-功能复核-v0.3.md)：目录包含图不等于学科先修结构，当前公共研究也未实现原站全部研究工具协议，章节素材与HTML产物历史仍有差距。历史测试数不作为本轮产品等价证明。

`已验证`须注明后端合同、真实文件、浏览器或真实模型的具体范围；这些证据不能相互替代。`本机适配`表示保留用户能力但采用不同技术；`外部未配/后续`不是已经可用的服务。分项证据与真实调用口径见[验证记录](mentrix-validation.md)，当前新增教材联动、个人总结、目录图鉴与PDF容量，分项结果见本轮验证；v0.3验收记录另存历史快照，不混作教学效果。

## 本轮真实记录的解释

扫描输入：隔离环境本机处理一份416页扫描输入，414页取得文字、5个正文真章。前置页和章后资料纳入文字/OCR核算；2页无文字保留partial。外部provider调用为0，知识点/讲义采用Mock检验全书调度链。章节可学不等于全文齐备，不证明真实模型整本学科质量。

联网研究：原gpt-4.1-mini实测检索或引用不足，未作为成功放行。经用户同意采用独立gpt-5-mini，一份completed真实回执有实际搜索与Bilibili/中文维基引用链。规范化URL去重后记录10个已引用来源和2个检索来源；对已有响应离线重核不新增付费调用。canonical来源硬限12、引用位置64、正文≤12000字符，不完整/假URL/无真搜索仍拒绝。

来源是公开检索/索引证据，不保证每次命中知乎，不声称已读全文/看完视频或已认证来源优质。一次研究计一次本机模型请求、进入导入100/200上限，托管搜索另收费；缺失费用字段不填假零。研究和讲义分别配置模型，逐点研究可关闭；未配或无可核验来源明确提示，不生成假报告。

历史基础验收使用自编分数材料和模拟作答。v0.3的7次受控调用、v0.4新增1次个人总结及旧tokens记录仅对应旧版本，见[验证说明](mentrix-validation.md)，不累计为本轮统一验收成绩。缺失进度与AI建议归因的新提示曾未经额外付费重测。基础链路可用不代表完整学科质量、长期稳定性、真实学生效果或账单验收。

教材原件、会话、密钥配置、OCR语言包和原始审计资料不随公开仓库发布。`platform/evix/`保留独立源码快照及来源清单，不表示其Next平台已经部署；原工作目录不参与当前系统运行。原师范生门户、课堂CSV工作台与既有PPT工具继续保留。

工程/图示/知识工作技能的固定来源见[技能吸收说明](engineering-skills.md)；Text-to-CAD按用户要求作为[后续模块](backlog/text-to-cad.md)登记，尚未启用。

**当前不称为“Mentrix全部功能等价完成”。** 本清单记录实际能力、证据层级和缺口，不把空页面、mock成功、未配置服务或建议分当作已经实现的外部能力与学习效果。

一课时任务包v0.5另完成1次真实调用（输入3707/输出3016 tokens），与上述v0.3/v0.4历史分开计数；使用自编材料与模拟班情，覆盖字段增量后未追加付费重测。新功能使用与边界见[教学包说明](teaching-pack.md)。
