# Mentrix 功能落实清单

说明快照：2026-11-16。当前主线是 **教材 → 章节/知识点 → 来源讲解 → 追问 → 练习反馈 → 本人笔记与学习成果**。这是根据可观察行为独立实现的学习系统，不连接 Mentrix 的账号或业务API，不把逆向报告当作原服务端源码。竞赛包装暂缓。

`已验证`须注明后端合同、真实文件、浏览器或真实模型的具体范围；这些证据不能相互替代。`本机适配`表示保留用户能力但采用不同技术；`外部未配/后续`不是已经可用的服务。分项证据与真实调用口径见[验证记录](mentrix-validation.md)，当前新增教材联动、个人总结、目录图鉴与PDF容量，分项结果见本轮验证；v0.3验收记录另存历史快照，不混作教学效果。

| 功能 | 当前实现 | 已验证范围与边界 |
| --- | --- | --- |
| 私人账号和资料库 | 密码注册登录、会话轮换/退出、用户及父对象权限、偏好持久化 | 本机适配；权限和持久化有HTTP及既有浏览器证据，非原站短信账号或公网生产认证验收 |
| 私有教材上传 | PDF/Markdown原件、哈希、传输与存储预算 | 教材PDF≤300MiB/3000页，Markdown≤5MiB；真实自编3000页与超过31MiB文件提取已验，未测试完整300MiB实体。使用本机私有上传 |
| 文档解析与课程结构 | 实际文字、页码、书签、可见目录/章标题；持久章节与知识点、人工校正、来源修订 | 自制5页PDF实际得到2章4知识点，重复解析ID与来源页边界已验；无可靠目录明确标为待修订分组 |
| 扫描件与图片OCR | 预装本机中/英文语言包、分范围识别、partial与继续处理 | 实际无文本层PDF及直接PNG均已识别；每任务≤5页。图片先查尺寸，直接图片边长≤4096/1200万像素；PDF内嵌图独立限1600万、OCR画布仍≤1200万像素/4096边长；高清扫描与待处理页恢复已修，OCR文字仍需核对 |
| 解析任务隔离 | 固定Node子进程、文件/像素/输出/时限预算、取消 | 实际坏图退出未终止父API；PDF内嵌图也有限额。进程隔离不是操作系统沙箱 |
| AI课程细分 | 给定来源页生成结构提案，页范围校验后由用户确认应用 | mock任务、坏输出和确认边界已验；每次≤20页。此项尚未纳入真实模型验收 |
| 来源讲解与风格 | 直觉、分步推导、来源示例、误区、自检；每版本保存风格和来源修订 | 默认中文讲解与真实引用已通过真实模型基础验收。default/中文保留英文术语/english的保存合同已验，未穷尽各风格内容质量 |
| 知识点追问 | 同上下文会话、回答版本、重新生成、刷新持久化 | 一次真实来源追问已验；取消、迟到、旧回答固定身份等由mock合同与浏览器分项验证 |
| 课题材料检索（M06） | 在本人ready材料与所选关联教材中按实际问题做有界关键词检索，保留真实页码、coverage及截断信息 | 自制25页PDF第24页证据已通过HTTP/mock验证；排除外人/已删材料，重新生成使用原用户问题。关联教材引用保留知识点修订与真实来源范围；不是向量检索或联网研究，不保证读完全文 |
| 选择题与简答题 | 来源、题型、题量和结构校验；作答前隐藏参考答案；提交幂等与草稿 | 真实模型分别完成选择题和简答题生成；模型题目、参考答案及适龄性仍需人工审阅 |
| 作答历史与反馈 | 本人作答回看、刷新恢复；选择题程序核对，简答AI建议反馈 | 历史、权限及坏输出/取消边界已验。真实示例选择题2/2由程序核对、未调用评分模型；简答AI给出5/5并保留requiresHumanReview=true，不是能力认证 |
| 显式揭示参考答案 | 题集GET和作答历史不提前返回答案；用户reveal后才给参考答案/解析 | 服务端、浏览器及导出门均有分项验证；未揭示时不能借批注猜A/B或导出答案 |
| 四类批注（M08） | 原文、固定讲解版本、固定对话消息、练习题目/解析/反馈；自动派生父链 | 后端与独立HTTP已验。旧superseded消息不跳到新回答；反馈重评分即使同文也stale。存在重复定位候选时保留人工核对标记 |
| 学习过程与成果汇编 | 当前来源讲解、本人笔记/追问、最新练习和本人最近作答/评分，分清AI与个人内容 | 实际Markdown及隐藏/已揭示答案导出边界已验；旧来源不当作新来源，作答和建议分不等于已掌握或教学效果 |
| 离线阅读与打印（M07） | Markdown默认下载；单文件HTML内嵌本地脚本、样式、数学字体并限制网络 | 实际file://浏览器阅读、数学渲染、无网络请求与浏览器打印PDF已验；这是HTML阅读包与浏览器打印能力，不是服务端PDF、DOCX或PPTX导出服务 |
| 课题文件管理 | PDF/PNG/JPEG/WebP/Markdown上传、私有预览、同类型重命名、软删除 | 正确MIME、nosniff/no-store、外人拒绝、迟到不复活已验；≤10个活动文件，删除可恢复数量槽位，原件bytes仍计入1GiB预算直到维护清理 |
| 进度与统计 | 用户自标未开始/学习中/掌握，真实账户记录计数 | 已验持久化；不从点击、作答次数或建议分推断真实学习提升 |
| 长任务与预算 | 持久任务、取消、重启中断、显式恢复、失败释放本机单位 | 负OCR单位绕过已修且有红绿例；同文件并发解析先409且不预留，顺序OCR保留既有页。单位不是供应商账单 |
| 最新前端接线（M09） | 四类批注框选/跳回、文件管理、作答/讲解版本、历史切换、新草稿、离线包 | 独立真实Chrome普通操作49/49通过，零页面异常；相同答案的新作答保留独立ID，旧作答与反馈可回看；390px无页面横向溢出 |
| 个人学习总结 | 按当前章节/目标，结合本人笔记、自标与作答/AI建议反馈生成；保存独立版本、来源与迹线指纹 | 一次真实模型基础调用已通过；范围省略、历史stale、取消与参考答案字段排除另行验收，详见本轮记录 |
| 知识图鉴 | 本人实际教材→章节→知识点的目录包含图、章节/名称筛选、分页与可操作列表 | 仅表示真实目录关系，不推断学科语义/先修/因果；来源跳转与窄屏检查见本轮记录 |
| 一课时教学任务包 | 目标/教材范围、教案、可增删节点与关系的图示、学生任务单、形成性评价、教师参考、版本修订/本人审阅、理解记录与分类复盘 | 人工全流程与独立HTTP/浏览器已验；学生JSON/MD/HTML严格白名单；来源页覆盖、stale/取消/迟到另验。一次自编材料真实模型通过；不等于真人教师审阅或教学效果。新包file:///打印检查受浏览器策略限制，详见验证记录 |
| 阅读与朗读 | 安全Markdown、四种常用数学分隔符、主题/字号、浏览器本机语音控制 | 数学整页10/10通过，代码保持原文，公式采用数量/长度预算；实际音频设备仍需核验 |
| 公告与反馈 | 独立公告、本人反馈及服务状态 | 本地接口已验；未复用原站公告、用户反馈或回复 |
| 短信、会员与支付 | 按用户决定暂不启用；保持明确未配置，不生成真实订单或验证码 | 当前学习系统范围暂缓这些商业服务，不阻断教材功能验收 |
| 联网研究与模型视觉追问 | 当前问答限于已授权、实际提取的文本来源 | web research、跨来源语义/向量检索及内联图片视觉模型追问仍未实现；图片OCR不等于视觉问答 |

真实模型验收使用自编分数教材与模拟作答。此前v0.3为7次受控调用（5成功、2次本地结构/引用拒绝）；v0.4新增1次个人总结成功，两版测试合计8次、6成功，输入5383、输出2180 tokens，模型为 `gpt-4.1-mini-2025-04-14`。人工走查后强化了缺失进度与AI建议归因，新措辞没有追加真实付费重测；细节见验证记录。基础链路可用不代表完整学科质量、长期稳定性、真实学生效果或账单已验收。

教材原件、会话、密钥配置、OCR语言包和原始审计资料不随公开仓库发布。`platform/evix/`保留独立源码快照及来源清单，不表示其Next平台已经部署；原工作目录不参与当前系统运行。原师范生门户、课堂CSV工作台与既有PPT工具继续保留。

工程/图示/知识工作技能的固定来源见[技能吸收说明](engineering-skills.md)；Text-to-CAD按用户要求作为[后续模块](backlog/text-to-cad.md)登记，尚未启用。

**当前不称为“Mentrix全部功能等价完成”。** 本清单记录实际能力、证据层级和缺口，不把空页面、mock成功、未配置服务或建议分当作已经实现的外部能力与学习效果。

一课时任务包v0.5另完成1次真实调用（输入3707/输出3016 tokens），与上述v0.3/v0.4历史分开计数；使用自编材料与模拟班情，覆盖字段增量后未追加付费重测。新功能使用与边界见[教学包说明](teaching-pack.md)。
