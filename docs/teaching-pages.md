# 教学工作区的三种全页视图

已有教学任务包现在支持原生全页入口，也保留教材内的弹窗入口。任务、版本、来源、本人审阅和导出仍使用同一组教学服务，不建立第二份数据。

| 页面 | 路径 | 真实能力 |
|---|---|---|
| 教学任务包 | `/textbook/:bookId/teaching` | 创建任务、选择教材范围、生成或人工草稿、逐块修订、版本回看、教师参考与本人审阅；教案与结构图并排预览 |
| 学生版预览 | `/textbook/:bookId/teaching/student` | 单独读取学生白名单DTO，只显示任务单、评价题、空白图与来源；当前完整且已审阅时可下载学生Markdown/离线HTML |
| 试讲与复盘 | `/textbook/:bookId/teaching/reflection` | 展示该版本真实教案的时间流程与检查提示；保存分类明确的本人记录、手写模拟材料或已授权去标识反馈；进入当前版本的AI学生对话 |

试讲页区分三种入口：“本人试讲记录”保存本人理解依据与复盘；“模拟演练记录”保存本人自行编写的合成情境；“模拟学生提问”通过真实模型服务进行AI学生对话。手写模拟记录不会自动变成AI消息，AI回复也不会被标为真实课堂观察。录音、转写与真实班级采集尚未接入。保存记录或完成对话都不代表学生掌握或教学效果。打印入口下载既有离线HTML，随后由浏览器打印，不是新的服务端PDF功能。

AI学生有好奇追问、易混淆、安静思考三种角色，须由本人明确开始。每会话最多12个已发起的教师轮次；取消、失败和显式恢复复用原发言，不追加轮次。消息与任务持久保存，刷新可回看；教学任务、教材来源或当前内容版本改变后，旧会话只读。模型仅接收安全教学任务、学生可见步骤/任务单和绑定教材，不读取教师参考答案、个人理解记录或复盘。界面明确标为“AI学生 · 模拟”，不作能力认证。服务与客户端合同分别见[AI学生服务](mentrix-student-simulation.md)与[对话组件](student-simulation-client.md)。

## 接线与生命周期

```js
const teaching = StudyTeaching.install({ api, getContext, notify, navigate });
await teaching.mount(host, { view: 'editor' }); // student / reflection
// 可选 packId、versionId 指定当前账户已有的任务与版本。
teaching.contextChanged(); // 账户、路由、教材/epoch变化时调用
teaching.unmount();       // 离开页面时调用；不删除保存的任务
teaching.open();          // 兼容原有弹窗
teaching.dispose();       // 最终销毁实例
```

`getContext()` 提供当前 `userId`、`epoch`、`book` 和 `outline`。模块只有一个outlet：切换到全页时从dialog移至host，打开弹窗时移回。卸载清除内容、取消等待中的轮询计时器、撤销视图令牌；已发出的请求即使迟到也不能覆盖新账户、新教材或新路由。轮询仅观察服务端任务，离开页面不等于取消后台生成。

全页复盘中的AI学生使用独立的`StudyStudent`组件；切换教学版本、试讲方式或卸载页面时同步卸载该视图，不改变服务端已保存的会话，也不自动取消后台模型任务。

学生页的版本列表和详情都显式使用 `?audience=student`，不复用编辑者或教师参考缓存，也不读取后台任务列表。教师参考仍需显式揭示本版本；新内容版本重置审阅，来源变化保留历史提示，导出继续服从服务端校验。

## 本轮验证边界

`node --test tests/study-teaching-client.test.cjs` 检查单outlet移动、学生请求和呈现白名单、过期/不完整导出门、异步旧视图、轮询释放、本人/模拟分类及账户变化。它使用合成DOM seam，不能证明浏览器排版、焦点或键盘行为；这些应在接线后由独立真实浏览器检查。旧教学服务HTTP测试仍验证既有存储与权限合同，不由本轮界面测试替代。

AI学生累计取得3次真实模型服务回应：好奇型原会话2轮，以及收束短答提示后独立易混淆型会话1次。输入仅为公开自编数学fixture，不是实际用户教材、学生或班级资料。这证明这些限定样例的真实调用链已接通，不证明各学科的回答质量、真实儿童反应或教学效果。合成HTTP/客户端测试与真实调用分别记录，不互相替代。

布局依据项目内批准设计稿16/17/18：重宋体标题、细线边界、编辑与图示双栏、学生纸页、真实分钟流程。窄屏改为单栏，交互不依赖动画；设计稿中的示例教材、固定数字和教学效果没有作为产品数据复制。
