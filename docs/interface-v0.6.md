# 界面与交互 v0.6

本轮针对书架、章节阅读和一课时备课工作台重做页面层级与排版，使用已有原生JS/CSS，不更换框架、不引入在线字体或动画库。原EVI-X工程与独立源码快照保持不变。

## 页面与行为

- **书架**：森林绿细导航、暖白页面、紧凑书脊卡片；上传、文件夹和查找独立成层。状态与数量均来自当前账户，装饰不冒充封面原图。
- **阅读器**：章节可折叠，中央正文独立滚动；助教按需展开。已有讲解时主操作是追问，重新生成、设备朗读与导出收进菜单。底部可继续前后知识点。
- **阅读位置**：本次会话内按账户、教材、知识点和内容标签保存位置；相同目录保留折叠与滚动状态。显式笔记跳转优先；用户输入会取消尚未执行的普通恢复，迟到回包不能覆盖新读者。
- **追问草稿**：未发送内容按教材/知识点或课题暂存于页面内存，切换后可回到原处；退出账户清空。它不是跨刷新或跨设备的草稿同步。
- **教学包**：左侧任务列表、右侧成果工作区充分利用窗口；教案、图示、任务单、评价、教师参考、复盘和审阅保留原业务门。切换成果页仅更新内容区，支持箭头/Home/End键。
- **移动与键盘**：导航、目录和助教按宽度变为抽屉；遮罩、背景inert、首尾焦点约束、关闭后归位和Esc恢复。阅读标签支持键盘切换，跳到内容不会改变教材路由。

原生SVG图标由项目代码绘制；未搬运Mentrix的图像、字体、用户内容或后端源码。图鉴仍是当前本地的目录包含关系；本轮没有凭视觉重构宣称先修推理、章备课流水线、逐token教学或联网研究已经实现。

## 动效边界

正文切换使用180ms局部透明度/轻位移，面板过渡约160–220ms。内容可用性不依赖动画结束事件，没有假的逐字AI输出或处理百分比。关闭、快速重开和尺寸跨断点会清理待执行焦点恢复，异步读者使用独立请求序列。

CSS与JS尊重`prefers-reduced-motion`；本轮真实浏览器偏好为普通动态，工具不能直接切换该偏好，**减少动态模式的实际操作仍待补测**。未进行帧率、长任务、弱机或真实手机性能剖析，不以短动画声明“全设备流畅”。

## 验证范围

以独立localhost域名和持久化合成账户执行真实浏览器操作，服务使用固定Mock输出，教材与班情是自编测试材料，没有新增真实模型调用。这些操作用于验证UI接线、恢复和交互，不证明真实模型内容质量或教学效果。

`npm run check`通过；现有渲染、批注、课程工具和教学包相关29项回归通过。桌面与390px下检查阅读主流程、折叠目录、标签键盘、助教/目录抽屉、焦点、草稿与任务取消；运行范围和未覆盖项另保留于本轮审查记录。历史v0.5的服务端、来源和答案隔离证据保持原有口径，见[验证记录](mentrix-validation.md)。

当前只更新独立项目；没有完成公网部署、多用户负载验收，也没有完成Mentrix全部功能等价。功能机制与缺口见[复核v0.3](reverse/Mentrix-功能复核-v0.3.md)，上线准备见[试点方案](deployment-pilot.md)。
