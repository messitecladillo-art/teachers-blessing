# 产品路线：从教材理解到教学实践

这里保存用户此前提出的方向，作为后续取舍依据。**已有**指存在本地实现及相应验证边界；**候选**尚未接成可用运行链，不能因为设计稿出现某个按钮或图形就标为完成。20页设计稿中的教材、图形、评分和学习结果含示例，实际页面必须使用真实来源、本人输入或明确标注的教学模板。

当前优先完成学习系统与原生界面，再持续改进“读懂教材—检查理解—形成教学成果—试讲复盘”。不是复刻所有Mentrix商业模块，也不以新增通用聊天入口代替学科功能。

## 可选实验，不自动激活

1. **动态学科图与实验**：当前概念实验室是手选贝叶斯通用模板，公式、概率树和数值由确定性计算得出。后续可按具体课程增加函数图、概率树、几何和参数实验；每个模板明确定义域、假设、边界与校验。任意知识点自动变成交互实验或AI插图仍是候选。
2. **AI学生与试讲对练的后续核查**：基础对话已接通真实模型服务，当前可选择好奇追问、易混淆、安静思考角色；显式开始，每会话最多12个已发起教师轮次，来源或教学版本改变后旧会话只读。本人手写模拟记录与AI消息仍分开保存，教师参考答案、私人理解记录与复盘不进入模型。真实调用累计取得3次回应（好奇型2轮、收束短答提示后的独立易混淆型1次），材料仅为公开自编数学fixture，非实际用户或班级资料；后续需要按学科核查角色适切性、来源一致性与教师应对，不能以模拟对话代表真实儿童反应、能力或教学成效。
3. **教研协作**：可探索教师共享草稿、评论、版本差异、审阅角色和授权素材范围。当前课题讨论是个人资料空间，没有自动建立团队、向外发消息或对接外部账户。
4. **更多导出与可访问性**：已有Markdown、独立HTML、浏览器打印及部分SVG/学生版导出。后续按真实需求评估DOCX/PPTX、版面稳定性、语义标签、屏幕阅读器、键盘与对比度；不能把已有门户PPT工具直接算成全部学习产物原生导出。
5. **费用与上线治理**：当前模型请求和搜索工具费用分别记录边界，本机任务单位不是账单。扩容前评估真实token/工具预算、任务恢复、备份、压力测试与权限；单进程JSON不直接等于多实例生产能力。见[试点上线方案](deployment-pilot.md)，当前不执行部署。

## 下一轮如何选范围

优先补影响教材主链的来源定位、真实目录可靠性、失败恢复和内容核对，再逐个选择学科模板或教学流程。每轮选一个可验收闭环：指定使用者、真实输入、实际动作、可保存成果、来源与版本、成本上限和失败路径；由合成合同测试、真实文件、浏览器与必要的受控模型调用分别验证。

新视觉仍以批准的20页为目标，具体原生路由与边界见[20页清单](ui20-pages.md)。真实学生、课堂观察与教学效果需要另外取得授权和证据；不能由生成设计、Mock模型、演练记录或点击量代替。

短信、支付与Text-to-CAD保持已登记的暂缓状态；此路线不承诺这些服务已启用，也不添加新的竞赛硬规则、奖项承诺或上线结论。
