## 真实模型基础验证

此前7次受控真实调用中，2次被本地结构/引用校验拒绝、5次业务成功。本轮另用此前自编分数教材、模拟答案与新增模拟笔记，完成 **1次真实个人总结调用并保存成功**，来源ID来自实际提供的知识点，保留`requiresHumanReview:true`和`coverage.partial`。

本轮模型为`gpt-4.1-mini-2025-04-14`，usage为输入2391、输出549 tokens。两轮受控测试共8次真实调用、6次成功、2次本地拒绝，输入5383、输出2180 tokens。只统计这次代理验证，不代表账户全部用量，也不推算未对账金额；导出和选择题程序核对没有额外模型调用。

人工走查确认总结涉及分数定义、同分母相加、本人笔记意图与已有作答反馈，并保留来源。同时发现模型将`recorded:false`的进度缺失表述为“未开始”。随后强化提示：缺失仅称“未记录进度”，状态归因用户自标，AI评分归因建议；正文使用已给标题/页段，内部ID只放结构字段。**新措辞未追加真实付费重测**；其来源与任务合同由mock复验，不能声称完整学科质量已通过。零上游调用的准备失败记录单独保留，没有计入8次真实调用。

## 运行和证据边界

- 总结绑定固定章节/目标及生成时记录；进入快照的来源、笔记、作答或评分改变会标记旧版stale。新版本不覆盖旧正文，旧版下载有历史提示。
- 标准答案、解析、量规及其受保护批注不主动提供给总结模型，即使已揭示；本人回答与已可见的AI建议反馈按个人记录提供。
- 来源与个人记录有明确预算、省略数量、选择策略及partial提示，不声称覆盖未提供的全书或全部历史。
- 图鉴只表示真实目录包含关系。当前RAG为中英文关键词检索；Embedding、向量数据库、重排序、联网研究及内联图片视觉问答尚未接入。
- 300MiB/3000页是接收上限，提取仍受400万字符、16MiB结果、180秒子进程及内存限制。没有测试完整300MiB实体，不保证每份稠密大文件均可处理，见[容量说明](mentrix-pdf-capacity.md)。
- 本机为单进程文件存储。公网多实例、实际语音设备与长期教学效果未验收，GitHub Pages不能运行私有账号及模型后台。

复现：`npm ci --ignore-scripts`、`npm run check`、`npm test`。OCR语言包可用`npm run setup:ocr`准备，Chrome可由`CHROME_PATH`指定；其它环境缺少可选资源时应如实记录skip。

原始独立审计、usage回执、模型输出和准备失败记录保存在被Git忽略的`.collab/mentrix-next/`，不发布密钥、会话、私有运行库或用户上传材料。实现方回归与独立复核分别归属；runner交互假设导致的初次失败保留，修正等待/操作条件后才计最终通过。
