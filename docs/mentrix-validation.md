## 单次真实模型检查

使用自编同分母分数教材和明确标注的模拟班情，通过实际上传/解析、创建任务、现有服务端模型适配、生成与持久化完成1次受控调用。配置请求模型为`gpt-4.1-mini`，供应商数值回执为输入3707、输出3016 tokens。

产物含4个教学环节、合计40分钟，结构与实际知识点来源ID通过校验；默认编辑DTO隐藏教师参考，合成测试用户显式揭示后可核读教师内容。没有提交真人教师审阅，也没有真实学生、课堂干预或效果评估。

核读发现任务单与评价题比较相近，实际使用时应进一步区分练习与迁移检查。来源ID合法、结构完整或一次调用成功，都不能证明内容全部正确或教学有效。用户需核对教材、公式、图关系、适龄性和参考答案。

这次调用发生在补充`source.pageCoverage`之前；新增覆盖元数据、提示和来源附录由合成HTTP增量复验，没有为提示微调再次付费。此前v0.3/v0.4合计8次受控调用（6次成功、2次本地结构/引用拒绝）仍归历史；本轮新增1次成功，不改写旧回执。

## 交付边界

- 教学包支持全包生成与人工空白草稿、教学块修订/历史版本、本人审阅、来源覆盖、两种受众下载、本人理解记录和试讲复盘。学生在线图判题、互动导师、复习调度与教研统计尚未实现。
- 扫描PDF保留实际页数、待处理页和超像素阻断页；每任务最多5页。PDF内嵌图16M像素、OCR画布12M像素/4096边长、直接图片12M像素的限制分别执行，不无界解码。当前OCR仍为本机Tesseract，未接入MinerU/PaddleOCR-VL或云端OCR。
- 页覆盖以所选来源页段为分母，显示实际有文字/缺文字页；不以书外待处理页误判完整的已选范围，也不以旧知识点残文掩盖全空页段。
- 当前RAG仍是有界关键词检索；课程图鉴表示目录关系，教学图表示本教学包待核对的教学关系，均不等于语义图数据库或GraphRAG。
- 教材300MiB/3000页是接收上限，仍受文本、输出、内存和时限约束；完整300MiB实体、长期公网多实例与真实教学效果均未验收。

独立复核、图像/字节检查、初次失败、红绿例与真实usage回执分别保存在被Git忽略的`.collab/lesson-pack/`，不随公开仓库上传。浏览器与实现方检查分开归属。可运行`npm run check`和`npm test`复现本机合同回归；OCR测试需私有本机语言包。
