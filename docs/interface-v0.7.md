# 界面与对照学习

本轮以用户认可的[原始界面提案](design/approved-ui-v1.png)为基准，重建暖白、森林绿、衬线标题、细线图标和纸页阅读界面。原始图是设计提案，其中的书封、来源卡和数据是示意；真实页面显示本人教材和实际服务结果。

## 原生页面

书架优先显示本人PDF物理第一页的私有缩略图；没有适用封面时使用独立生成的设计背景和可编辑标题。侧栏提供教材、备课、研读、笔记、收藏和设置入口，首页保留原门户。顶栏移除“AI已连接”提示，AI内容说明集中在合适的位置。

章节主页与目录按真实章组织。阅读页标题直接衔接内容标签，朗读及导出收进顶栏更多菜单；章节底栏固定在阅读区域底部，左侧上一章、中间收藏与笔记、右侧下一章，实际链接指向真实章ID。来源页码只作来源信息。

研读页使用综合报告、来源卡和分类标签。收藏持久化到本人账号；已有批注、讲义版本、会话与学习记录继续使用原有来源约束。

[原页对照提案](design/compare-ui-v1.png)已有原生实现：左侧显示原始PDF页面，右侧为当前知识点讲义，支持来源范围、翻页、缩放和分栏。页图由绑定原件的指定物理页生成；非PDF材料显示真实原文片段。失败时保留原件下载，不用OCR重排文本代替页图。

## 设计与实现的区别

成套页面设计总览标明当前实现及其边界。生成一张设计图不表示相应产品能力已经运行。图形生成工具目前用于开发素材；应用内已有教学包可编辑图示。概念实验室已有手选贝叶斯通用教学模板，概率树、公式与数值由确定性计算产生；这不等于根据任意知识点自动生成概率树、函数图或通用AI插图。

知识图鉴包含真实目录图和本人手工先修建议DAG；后者可保存、拒绝循环并处理版本冲突，仍不是自动推断的学科先修事实。学习前诊断使用实际4道选择题、本人提交与信心自评；提交前不揭示参考答案，不把题分当作能力认证。站内复习已支持自评后的固定1/3/7/14天安排、延期、取消与旧来源重建，不承诺记忆效果或外部提醒。

试讲与复盘中的AI学生已接真实模型服务，三类角色与教学包当前来源、版本绑定，每会话最多12个已发起教师轮次，支持持久历史、取消和显式恢复。它与本人手写的模拟演练记录分开，所有回复均明确标为模拟，不能当作真实学生反馈或教学能力评分。受控真实调用累计取得3次回应（好奇型2轮、独立易混淆型1次），材料仅为公开自编数学fixture，未使用实际用户或班级资料；不能据此推出普遍回答质量或课堂效果。

字体来自Adobe官方思源宋体CN Heavy并保留OFL许可，界面图标为可编辑SVG。页面使用原生HTML/CSS/JavaScript，没有将设计稿整张铺作可点击页面。素材说明见[界面资产](../assets/ui/README.md)。

实际验收分别记录路由、上传与处理、收藏、研读、备课、键盘与窄屏行为。后续新增的知识图鉴、实验、诊断、复习、笔记、反馈、记录与设置有独立浏览器正常流程复核；390px设置页的溢出与抽屉行为另行检查。原页对照已检查实际PDF页图与翻页后保持知识点。相关Node检查、合成DOM检查、真实浏览器检查和像素比对各自记录，不互相代替，也不将合成内容当作模型质量或教学效果。

全部页面入口和明确能力边界见[20页清单](ui20-pages.md)。登录页使用用户认可的书籍植物版画插画；书架封面仍优先显示本人PDF原件，而非装饰插画。
