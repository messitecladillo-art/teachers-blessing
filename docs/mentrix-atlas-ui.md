# 原生全页知识图鉴

`study-atlas.js/css`提供`window.StudyAtlas.install({api,getContext,navigate,notify})`，返回异步`mount(host)`、`contextChanged()`、`dispose()`。context为当前`userId/epoch/book/outline/books`；根页面分别将全局`#/atlas`与教材内`#/textbook/:id/atlas`挂到同一个原生工作台。全局导航和页头由根页面提供，不使用截图或iframe覆盖功能。

## 实际能力

- 从本人教材读取真实outline，按章、名称、已有类型筛选；没有类型时明确“未标注”，目录不可靠时提示核对，不绘制页块假章。
- “教材目录”图只画书→章→知识点的隶属关系。“先修关系”读取人工建议，不从章节序号推断学科事实。完整关系清单与添加/删除草稿、显式保存均可操作。
- PUT使用`expectedRevision`；冲突保留草稿并要求重新载入。来源与图谱都仍待核对。单次最多100边，前端预检自环/重复/循环，服务端再次校验。
- 每页24个真实知识点，图与键盘清单同页；页数和范围明确显示。跨页先修边不画成不存在的节点，完整边仍列出核对。
- 选中知识点读取实际来源，右栏最多显示900字；点击“进入学习”导航原阅读路由，不自动调用模型。标题、来源、备注均通过textContent写入，原文不作为HTML执行。
- 教材切换、账号epoch改变、卸载和会话结束阻止旧回包绘制；保存时锁定草稿编辑。

## 图稿对齐与验收边界

已实际核读第08页1586×992设计稿并采样底色：森林绿约`#174033`、纸色`#f9f7f3`、表头`#dbe0cd`。桌面内容采用左240px、中间余量、右420px；表格跨中/右两列，标题留128×184px真实首页封面位，使用`Xunzheng Display`900字重。无PDF封面时使用真实书名占位，不复用设计稿中的虚构教材图。

本模块完成9项Node纯函数/DOM seam验证，覆盖真实范围、分页分母、关系语义、保存/删除/循环/冲突及旧账号/旧教材回包。该检查不是浏览器、CSS排版或截图像素验收。本轮未启动浏览器；根页面接线后仍须在1586×992比较实际底色、列宽、字体和形状，并检查窄屏与键盘。不能将本说明称为已通过100%视觉还原。
