# 一课时教学任务包

在教材左下角点击“备好一堂课”，打开“一课时教学任务包”。每个任务固定本课目标、教学对象、课时和教材范围，产物可逐块修订，保存为独立版本。

## 使用流程

1. 先解析教材；扫描PDF先在本机识别本课相关页面。没有可验证文字的章节不能用来生成教学包。
2. 创建任务卡：填写名称、年级、学科、5至120分钟的课时、本课可观察目标、本人提供的先备知识与班情，再选择教材章节。
3. 生成待核对教学包，或从空白草稿开始。未配置模型时仍能保存人工草稿；不会模拟AI生成成功。
4. 分页查看教案、教学图示、学生任务单、形成性评价题、教师参考和复盘提示。各部分可通过表单修订；每次保存建立新版本，保留历史。
5. 在“教师参考”中显式查看当前版本的答案与解释，再核对来源、内容与适龄性并确认本人审阅。目标、来源或内容变化后，新版本需重新审阅。
6. 下载学生版或教师版的Markdown/单文件HTML。HTML可离线打开并使用浏览器打印。学生版只包含学生任务、评价题、空白图和来源附录；不包含教师参考、检查要点、教案教师行动、理解记录或复盘材料。
7. 保存本人展示理解、误解修正或自述先备知识，并附具体解释、作答或演示。试讲复盘注明自评/同伴反馈/课堂观察及模拟、自述或已授权去标识的材料性质，分别记录观察、反例和下次行动。

## 内容与版本边界

- 输入仅从当前用户所选教材的有效知识点派生；不接受客户端自造来源。单次最多10个知识点、24000个来源字符，省略、截断及页段内缺文字的覆盖信息在coverage中记录；来源附录显示该范围实际有文字的页数。
- AI输出必须通过结构、实际来源ID、图节点/边、全局题目ID、教师答案对应及活动时间校验，教案时间总和须等于课时时长。结构检查不能证明知识、适龄性或教学效果正确，仍需用户审阅。
- 人工空白草稿和未填完版本明确标为不完整，不能作为已完成成果审阅或下载。每任务最多50版本，每版本最多20条理解记录与20条复盘。
- 默认API是作者编辑DTO，隐藏教师参考答案；显式学生DTO和学生下载采用白名单。教师参考只按用户明确揭示的版本提供，不继承另一版本的揭示状态。
- 来源/任务更新、生成中人工发布新内容、取消或删除父教材，都不能让迟到结果覆盖新成果。任务沿用现有私有队列、本机预算、取消与显式恢复。
- 本人记录、AI草稿和本人审阅分别归因；不从浏览、点击、自标进度或保存记录推断真实掌握，不生成虚构班级样本或教学干预效果。

## 当前范围

本轮支持全包AI生成、空白人工草稿、已有教学块的表单修订、独立版本、来源核对、本人审阅、理解/试讲记录及两种受众的离线成果。图示是可修订结构与静态教学图，不是拖拽画布或学生在线图判题。没有自动课堂录音、班级数据采集、教研统计推断或自适应复习调度。

当前OCR依然是本机Tesseract；[高清扫描恢复](mentrix-scan-recovery.md)已单独修复。MinerU/PaddleOCR-VL属于后续可选专用解析后端，尚未安装或接入。
