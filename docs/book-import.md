# 整书按章导入

导入PDF或Markdown后，一次提交依次执行文字提取、必要的本机OCR、真实目录识别、按章整理知识点和准备讲义。已完成章节可以先学，关闭进度窗口不停止后台任务。页码是来源定位和原页阅读控制，不是课程章节。

## 目录与来源

- 优先使用PDF书签；没有可靠书签时对齐正文中的真实章首。目录上的印刷页码不能直接当PDF物理页码。
- Markdown使用实际一级标题及文字偏移定位，多个章节可共享物理第1页。
- 后文提及“第二章”的叙述、重复页眉、目录续页及章小结不能自动变成新章。物理章首识别还会将明确的书末习题答案、参考文献和索引留在课程章节外。
- 没有可靠章节时停止并请用户核对目录，不按固定页数制造章节。手工目录以用户明确保存的边界为准。
- 全书OCR也核算前置页及书末材料；有页面仍未取得文字时显示处理结束且待核对，不冒称全文识别成功。

长章节在内部可分片处理，结果合并回同一真实章节。当前每片受文字和来源页数预算限制，原有5页OCR批次是内部安全限制；用户不用逐批输入页码。OCR超时会缩小批次，已识别页和已完成模型片段保留。

## 选项与预算

`POST /api/v1/textbooks/:id/import` 接受：

```json
{
  "scope": "all",
  "prepareLessons": "all",
  "externalResearch": "auto",
  "ocrLanguage": "chi_sim",
  "maxModelCalls": 100
}
```

`scope=chapters`时提供本人真实目录中的`chapterIds`。讲义可选全部、首章或暂不准备。`externalResearch=auto`在服务已配置时按知识点检索补充资料，`off`只使用教材。普通OCR不消耗模型请求单位；知识点整理、外部研究请求和讲义分别计入本次累计请求数。上限默认100，最多200；托管搜索工具费用另计，本机单位不是供应商金额。

进度是持久化任务，可取消、恢复或在预算恢复后继续。恢复不清零累计调用数；增加本次上限须明确提交新值。来源文件、哈希或人工目录改变后，旧任务不得覆盖新版本。讲义复用同时核对知识点修订和实际使用的研究版本。

## 验证边界

自编PDF与合成模型测试覆盖长章不拆散、同一处理批次跨章不混合、印刷页码偏移、无可靠目录、取消、重启、预算暂停、属主隔离和来源冲突。一次私有隔离扫描验证处理416页，414页取得文字并定位5个真实章；课程生成使用固定Mock，不能作为真实学科讲解质量证据。真正的OCR、Mock模型合同、真实联网检索和实际教学效果分别记录，不相互替代。
